# AUTORADAR — автономный бесплатный MVP

Этот репозиторий одновременно является:
1. сайтом AUTORADAR;
2. парсером публичных объявлений;
3. планировщиком обновлений;
4. JSON-хранилищем текущих данных и истории цен.

## Бесплатная инфраструктура

**GitHub Pages** публикует `index.html`, а **GitHub Actions** запускает сборщик по расписанию.

Расписание в `.github/workflows/autoradar.yml`:
`3,18,33,48 * * * *` — примерно раз в 15 минут.

Важно: GitHub не обещает запуск cron точно в указанную секунду; при нагрузке запуск может задержаться.

В `config.json` есть слоты для Avito, 2ГИС и VK. Они намеренно не обходят CAPTCHA или авторизацию. Для них лучше подключить публичный URL, API или дилерский фид.

## Умный режим, чтобы не перегружать площадки

Каждые 15 минут Drom проверяется на уровне списков объявлений.
Auto.ru — раз в 30 минут.
Сайты дилеров — раз в час.

Детальная карточка открывается, если:
- объявление новое;
- изменилась цена/карточка в списке;
- детальная карточка не проверялась 24 часа.

По умолчанию за один цикл открывается не более 35 подробных карточек. Это задаётся `detail_budget_per_run` в `config.json`.

## Что хранится

`data/current.json`
- все текущие исходные объявления;
- объединённые карточки автомобилей;
- список источников;
- статус мониторинга.

`data/history.json`
- история изменения цены по каждому source listing.

`data/state.json`
- техническое состояние для быстрого следующего обхода.

## Как опубликовать бесплатно

### 1. Создать PUBLIC-репозиторий GitHub
Например `autoradar-tyumen`.

### 2. Загрузить ВСЁ содержимое этого архива в корень репозитория
Папка `.github` тоже обязательна.

### 3. Включить GitHub Pages
Repository → Settings → Pages → Source → **GitHub Actions**.

### 4. Дать Actions право писать в репозиторий
Settings → Actions → General → Workflow permissions →
**Read and write permissions** → Save.

### 5. Запустить первый большой сбор
Actions → `AUTORADAR Collector + Pages` → Run workflow.
Для `detail_budget` можно поставить `120`.

После выполнения сайт будет по адресу:
`https://USERNAME.github.io/autoradar-tyumen/`

После этого вручную ничего обновлять не нужно.

## Почему репозиторий должен быть публичным

Стандартные GitHub-hosted runners бесплатны для public repositories. Для private repositories действуют лимиты бесплатных минут.

## Ограничение GitHub

Scheduled workflows в публичном репозитории GitHub может отключить после 60 дней отсутствия активности репозитория. В проекте есть ежедневный `data/heartbeat.txt`, поэтому бот сам создаёт регулярную активность при успешных запусках.

## Локальный тест на Windows

1. Установить Python 3.11+.
2. Запустить `install_windows.bat`.
3. Запустить `run_local_windows.bat`.
4. Открыть `http://localhost:8000`.

## Как подключить Avito / VK / 2ГИС позже

Не надо ломать основной проект. Добавляем отдельный collector в `scraper/collectors/` и источник в `config.json`.
Обход CAPTCHA и закрытых страниц проект не делает.

## Масштабирование

После Тюмени конфиг можно расширить:
- другие бренды;
- другие города;
- дополнительные дилеры;
- API/XML-фиды.

Когда объём станет слишком большим для GitHub Actions, тот же Python-код можно перенести на VPS/Railway без переписывания frontend.


## Частота сохранения данных

Проверки запускаются примерно каждые 15 минут, но Git-коммит создаётся:
- сразу, когда реально изменилась структура/цена/условия рынка;
- либо примерно один раз в час для обновления отметки свежести.

Это не раздувает историю репозитория 96 техническими коммитами в сутки.
